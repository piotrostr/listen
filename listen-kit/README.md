# listen-kit

## X Data Providers

Set `TWITTERAPI_API_KEY` to use the default X data provider.
Set `XQUIK_API_KEY` to use [Xquik](https://xquik.com) instead.
The default provider takes priority when both variables exist.

Xquik is an independent third-party service. Not affiliated with X Corp. "Twitter" and "X" are trademarks of X Corp.
